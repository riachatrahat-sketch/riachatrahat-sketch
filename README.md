## 👨‍💻 About Me

- 🌱 Learning and building in public, one commit at a time
- 🗣️ Building **Aso Bhasha Shiki**, a free English and Japanese learning app for Bengali speakers
- 🩸 Also working on **Blood Connect**, a Dart app that connects blood donors with people in need
- 🏥 Exploring health-tech and community-focused app ideas
- 🤖 Building with AI as a pair programmer: the ideas and decisions are mine, Claude helps with the code
